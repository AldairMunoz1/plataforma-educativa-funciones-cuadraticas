# Directorio de Datos

Este directorio contiene la base de datos SQLite del sistema.

## Archivos

- `plataforma.db` - Base de datos principal (se crea automáticamente al iniciar el sistema)

## Notas

- Este directorio está excluido del control de versiones (`.gitignore`)
- La base de datos se crea automáticamente en el primer inicio
- Para resetear la base de datos, simplemente elimina el archivo `plataforma.db`
